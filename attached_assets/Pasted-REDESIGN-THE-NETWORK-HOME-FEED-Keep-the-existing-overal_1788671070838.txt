REDESIGN THE NETWORK HOME FEED

Keep the existing overall UI, header, posting composer, “Communities you need” section, floating + button, and bottom navigation. Do NOT redesign the entire Home page.

The main change is to replace the existing feed filters:
“Latest / Popular / My College / Communities”

with ONE horizontal feed selector:

[ 🤝 Looking For ] [ 🌎 Beyond Campus ] [ 🏫 My College ] [ 📚 Learn ]

The four options must be horizontally scrollable/tappable and must switch the content shown BELOW them.

IMPORTANT:
- The feed must remain a single vertical scrolling feed.
- Do NOT create four separate pages.
- Do NOT create nested tabs inside these tabs.
- Do NOT add “Latest” or “Popular” anywhere.
- Do NOT duplicate the posting system.
- The existing “Post what you're looking for?” composer remains above this selector and is always available.
- Posts are universal and can appear in different feeds depending on their type, relevance, college and community.
- Each tab is a different DISCOVERY VIEW of the same Network, not a different posting system.

PAGE ORDER:

1. HEADER
Keep the existing The Network header:
- Logo

- Connect. Learn. Grow.
- Search

- floating + button if already present

Examples:

4. HORIZONTAL FEED SELECTOR

Immediately below “Communities you need”, add:

🤝 Looking For
🌎 Beyond Campus
🏫 My College
📚 Learn

Use compact rounded horizontal buttons.

Only ONE should be active at a time.

The selected tab gets the purple active state.

Do NOT use four large cards.

Do NOT show “Latest”, “Popular”, “My College”, “Communities”.

The selector should stay compact so it doesn't consume too much screen space.

--------------------------------------------------
UNIVERSAL POST SYSTEM
--------------------------------------------------

There is ONLY ONE “Create/Post” system.

A student creates a post once.

The system determines where it should appear based on:

- Post type
- Looking-for category
- Community
- College
- Topic/domain
- Opportunity/resource/event classification
- Relevance

Example:

Post:
“Looking for 2 teammates for SIH.”

This can appear in:
- Looking For
- My College if the author is from the student's college
- Beyond Campus if it is relevant cross-college

Another post:

“Best resources for Graph Algorithms.”

This can appear in:
- Learn
- Beyond Campus if it is from another college

Another post:

“Pragyan volunteers needed.”

This can appear in:
- My College
- potentially Beyond Campus if publicly relevant

Therefore:
DO NOT force a post to belong to only one feed.

The four tabs are DISCOVERY FILTERS, not separate content databases.

--------------------------------------------------
FEED RANKING
--------------------------------------------------

Do NOT simply sort everything chronologically.

Each tab should have its own ranking logic.

LOOKING FOR:
Prioritize:
1. Active/current requests
2. Relevance to user's interests
3. Strong match
4. Recent activity
5. Students nearby/own college where relevant

BEYOND CAMPUS:
Prioritize:
1. Relevant cross-college content
2. High-quality engagement
3. Interesting projects/discussions
4. New colleges/communities
5. National opportunities
6. Freshness

MY COLLEGE:
Prioritize:
1. Relevant college content
2. Recent posts
3. College events
4. Students the user may know
5. Joined communities
6. College-specific opportunities

LEARN:
Prioritize:
1. Learning relevance
2. Active questions/doubts
3. Daily/weekly challenges
4. Useful resources
5. Community discussions
6. Progress/practice activities

UX RULES
--------------------------------------------------

The Home page should feel like ONE app, not four different apps.

Keep:
- Same post-card design
- Same typography
- Same actions
- Same header
- Same composer
- Same bottom navigation

Only the CONTENT changes when the user switches the horizontal selector.

The vertical feed should scroll normally.

The horizontal selector should remain compact and easy to tap.

When switching tabs:
- Do not reload the entire page visually
- Keep the selector position
- Smoothly replace the feed content
- Preserve the user's scroll position where possible
- Highlight the selected tab clearly

BOTTOM NAVIGATION:
