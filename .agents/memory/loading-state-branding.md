---
name: Loading-screen preference
description: The user's preference for loading screens in The Network's signed-in app.
---

Signed-in loading states should show only a simple animated-dot spinner and the text “Loading...”. Do not show the logo, wordmark, or explanatory subtitle.

**Why:** the user asked to replace the branded loading screen with a dots-only animation and no additional loading copy.

**How to apply:** Use the same minimal indicator for signed-in startup and feed loading. Keep public landing and authentication screens unchanged unless separately requested.
